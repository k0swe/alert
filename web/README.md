# Signal Bell web app

This directory contains the Angular frontend for [Signal Bell](../README.md).

## Development server

```bash
npm ci
npm start
```

Open <http://localhost:4200/>. The development server reloads when source files change.

## Tests

```bash
npm run test:ci
```

## Production build

```bash
npm run build
```

Build artifacts are written to `dist/web/browser/`.
